Loop Board Exporter

This extension works on the Microsoft Loop website, not on this tab.

  1. Open Microsoft Loop in Edge or Chrome.
  2. Open a Board and apply any filters in Loop.
  3. Open one card in the filtered Board.
  4. Click the Loop Board Exporter toolbar icon.
  5. Export to JSON, Markdown for AI, or Excel-compatible CSV.

All data is processed and stored locally in your browser. The extension does not connect to an AI.
